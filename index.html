Tabelas

    Sistema de Gestão de Vendas, Compras e Controle Financeiro

    Escopo: Banco de dados para a Ponce, empresa de revenda sem estoque físico próprio, que centraliza clientes, vendedores, produtos, fornecedores, vendas, itens vendidos, compras e notas fiscais para apoiar o controle financeiro, relatórios de faturamento e a tomada de decisão. Projeto da disciplina Modelagem de Banco de Dados (UNICID), orientado pelo Prof. Dr. Diego Carvalho.

    Tecnologia: MySQL

    Data Literacy

    Data literacy é a capacidade de ler, interpretar, avaliar e comunicar dados com responsabilidade. Neste projeto, o dicionário explica o significado, a origem, as regras e os acessos de cada atributo para apoiar decisões informadas, identificar limitações do modelo e proteger dados pessoais.
